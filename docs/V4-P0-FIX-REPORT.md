## 2. 根因与方案

### 2.1 项目概览显示 0 个（数据可信问题）

**根因**：`projectRanking` 只从日志/已完成任务反推项目行；一个「有 5 个任务、0 完成、0 专注」的项目在两张表里都没有记录，于是根本不存在于结果集。Dashboard 再按 `length` 显示，就成了「0 个项目」。

**方案**：增加 `includeEmpty` 选项，**默认 false**（Stats 等旧调用行为完全不变），Dashboard 传 true。排序仍按投入量，但不再过滤。计数用全量 `allProjects.length`，列表只展示前 3 个。

### 2.2 连续记录文案

标签改为「连续记录」，`title` 提示「按有任务完成或专注记录的日期计算。」
**未改 `countStreak` 逻辑**；但也没有逐行审计它与这句说明是否完全一致——如果后续发现它其实只认任务完成，需要再对齐文案（列为待确认项）。

### 2.3 零值降噪

- 任务行：`taskFocusMinutes === 0` 不渲染时长；
- 近 7 日：`weekMinutes === 0` 时标题只留「全部项目」，不显示「合计 0m」；
- 进度条：`showValue` 后 0% 也显示数字，不再是一条看不见的线；
- 保留有意义的零：任务数 `0/5`、项目数 `N 个`、完成率 `0%` 都保留。

### 2.4 空态

- 柱状图：全 0 直接返回空态（160px，居中一句），**不画轴**；
- 甘特图：无任何完成项时返回 120px 空态，不画轴、不画空日期；
- Dashboard 近 7 日：`StateView` + 「去专注」按钮（复用 `onNavigate('timer')`）；
- `StateView` 空态加 `minHeight:120`，空卡不再被 2×2 网格拉到整行高度。

### 2.5 横向溢出

**未在真实宿主复现测量**，因此按「可复现的样式缺陷」做防御性修复，而不是 `overflow-x:hidden` 掩盖：

- `.osb-log-filters` 允许换行，子项 `min-width:0`，select/input `max-width:100%`；
- `.osb-add` 允许换行，输入框 `flex:1 1 180px`；
- `.osb-grid > *`、`.v4-glass-*`、`.v4-dash > *` 补 `min-width:0`；
- `.v4-scope` `max-width:100%; box-sizing:border-box`。
