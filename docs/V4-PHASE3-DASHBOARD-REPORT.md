| React 组件 | **14 / 14**（原 10 项 + C11–C14） |

### 上一轮 SIGTERM 的根因与修复

不是测试失败，是**进程不退出**：Dashboard 的 `useNow` 留下 30s `setInterval`，Node 没有活跃句柄结束时不会退出，被工具的 timeout 杀掉。修复：测试末尾 `cleanup()` + `dom.window.close()` + `process.exit(failed?1:0)`。复跑后 14/14，无中断。
