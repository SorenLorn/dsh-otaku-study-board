# Phase 5.1.3 — 产品架构与 Dashboard UX 重构

> 本阶段把 V4 变成唯一面向用户的工作台，删掉展示型 Hero，重排 Dashboard 与 Tasks。
> 不改数据层、Actions、存储 Schema，不删 V3 代码。
> 截图来自**独立 Chromium 整页测试**（真实 `BoardPage` + 真实 `board.css`），不是 DSH 宿主。

## 1. Classic / V4 功能差异

数据层、Actions、Hooks、存储键**完全共用**（V4 只是另一套视图）。差异在功能覆盖：

| 能力 | V3 Classic | V4 | 处理 |
| --- | --- | --- | --- |
| 任务增删改查 | ✅ | ✅ | 已覆盖 |
| 优先级 / 截止 / 项目 / 备注 | ✅ | ✅ | 已覆盖 |
| 搜索 / 状态筛选 / 排序 | ✅ | ✅ | 已覆盖（项目筛选改为全局选择器） |
| 子任务 | ✅ 增删勾选 | 只读展示 | 保留经典；后续补 V4 |
| 预估时长 | ✅ | ❌ | 保留经典 |
| 开会话 / 绑定会话 | ✅ | ❌ | 保留经典 |
| 专注计时（含短休/长休/跳过） | ✅ | ❌（「打开计时器」跳经典） | 未来 Focus 页 |
| 会话日志 / 采集 / 斜杠命令 | ✅ | ❌ | 未来 History 页 |
| 数据看板（5 图 + 5 折叠面板） | ✅ | 仅 7 日趋势 | 未来 History / Analytics |
| 项目新建 / 模板 / 归档 / 快照 | ✅ | 仅切换项目 | 未来 Settings |
| 备份导入导出 | ✅ | ❌ | 未来 Settings |
| 阻碍记录 / 月度目标 / 上下文观测 / 调试 | ✅ | ❌ | 未来 Settings / Insights |
| 「重置今日」 | ✅ | ❌ | 保留经典（低频、破坏性） |
| 双语 Hero / 名言 | ✅ | 已删除 | 不再需要 |

**结论**：V4 覆盖了日常高频的「看状态 + 管任务」，但没有覆盖计时、日志、备份、项目管理和任务增强。
因此本轮**没有**宣称 V4 已覆盖 V3；未迁移的功能统一从「经典工具」进入，且在那里保留完整能力。

## 2. 工作台入口调整

### 改前

- `BoardPage` 默认 `view = 'classic'`；
- 页面右上角有 `ViewTabs`（经典工作台 / V4 Dashboard），下面还有 Dashboard / 任务 二级切换；
- Hero、项目条、五个 V3 卡片在默认路径上。

### 改后

```
默认 → V4（V4Shell + Dashboard）
         ├─ 顶部导航：Dashboard / 任务
         ├─ 顶部操作：新建任务（仅首页）、经典工具
         └─ 项目选择器（全局作用域）

经典工具（临时兼容层）
         ├─ 入口：工具栏「经典工具」，或 URL 加 #classic 打开
         ├─ 顶部虚线提示条：「经典工具 · 计时、会话日志、备份与项目管理」
         └─ 「← 返回工作台」回到 V4
```

- `ViewTabs` 不再被页面引用（组件与 C22 测试保留，作为内部备用；后续可删）。
- 经典模式没有 V4 切换器，只有一个明确的「返回工作台」按钮。
- 所有未迁移功能仍在经典模式里**完整可用**，不存在「为了简洁被丢掉」的功能。

## 3. Hero → 紧凑工具栏

### 删除的内容

- 双语大标题 + 副标题（`Sorchron Study Board` / `Track focus, iterate steadily`）；
- 一段英文产品说明（`A local-first study workbench for DSH...`）；
- 装饰性双语名言（`慢一点没关系...`）；
- 34px 图标块 + 多行留白 + 日期独占一行。

### 新工具栏（约 48px）

一行：品牌标 + 「溯时学习工作台」+ 小号 SORCHRON｜Dashboard / 任务｜**项目选择器**｜日期｜新建任务｜经典工具。

- 没有英文副标题，没有说明文字，没有引言；
- 日期在 <720px 隐藏，品牌副标在 <720px 隐藏；
- 项目选择器直接绑定 `useBoardData().activeProjectId`，与全局作用域一致。

## 4. Dashboard 新布局

### 4.1 三层结构

```
[统计带 L1]  今日任务 7 个 | 今日完成 2 个（环形） | 今日专注 50m | 连续学习 7 天（7 点）
[主工作区]   今日任务（L1，可勾选完成，最多 6 条，查看全部 →）   |   专注（L2，今日/本周/峰值 + 打开计时器）
                                                              |   项目进度（L2，前 3 个项目 + 完成 x/y）
[辅助层]     近 7 日专注（L2，sparkline + 峰值）              |   最近活动（L2，5 条）
```

- 统计指标按要求改为：**任务总数 / 今日完成 / 今日专注 / 连续天数**（本周专注移到「专注」卡的副行）；
- 今日任务支持**直接勾选完成**，走 `useBoardActions().completeTask`，与 Tasks 同一条链路（Daily / Timeline 一起更新）；
- 辅助信息（趋势、活动、项目排名）降为 L2，不与主工作区抢层级；
- 没有为每个数字单独建卡：4 个指标共用一块玻璃 + 发丝分隔。

### 4.2 数据口径

| 指标 | 来源 |
| --- | --- |
| 今日任务 | `computeBoardStats().tasksTotal`（当前项目作用域） |
| 今日完成 | `tasksDoneToday`（`completedAt` 落在今天） |
| 今日专注 | `focusMinutesToday`（focus 日志） |
| 连续学习 | `countStreak()`（有完成或专注的连续天数） |
| 项目进度 | `projectRanking(includeEmpty: true)` + 任务完成数 |
| 趋势 | `daily.focusMinutes` 近 7 天 |

口径一处没改；组件测试 C36/C46 覆盖「项目完成 1/2」与「勾选写回」。

## 5. Tasks 新布局

```
[任务  7 个任务 · 2 已完成 · 1 逾期]        [搜索] [排序] [新建任务]
[全部 | 未完成 | 已完成 | 逾期]
[行内新建 / 编辑面板（按需展开，5 个字段，3 列 → 720 单列）]
[任务列表 L1：行高 ~54px，发丝分隔，右侧 编辑 / 删除]
```

- 标题、计数、搜索、排序、新建在**同一行**（≤720 换行，搜索独占一行）；
- 去掉了页内重复的「项目筛选」下拉：项目作用域由顶部工具栏统一控制，避免同屏两个项目选择器；
- 新建表单不再是独立大卡片压住列表：改成列表上方的紧凑面板（标题占整行，优先级/截止/项目一行，备注一行），`Enter` 直接提交；
- 行内操作保持可发现：勾选圈、编辑、删除（删除仍二次确认）；
- 保留全部 CRUD、筛选、排序、项目归属；`createSignal` 让首页「新建任务」直达表单。

## 10. V3 隔离

- 本轮新增样式全部是 `.v4-*`（`.v4-shell/.v4-topbar/.v4-nav/.v4-dash*` 等）或 `.v4-classic-bar`；

- 经典模式顶部只多了一条 `.v4-classic-bar` 提示条（虚线、12px），不影响 V3 卡片本身。

## 12. 未完成 / 风险

1. **真实 DSH 宿主未验证**：本轮没有启动或重启 DSH；`lib/client.js` 已更新，宿主需要刷新页面才会加载新 bundle。
2. **经典工具是临时入口**：计时、日志、备份、项目管理、子任务/预估/会话绑定仍在经典模式；迁移完成前不能移除该入口，否则就是丢功能。
3. **V4 首页没有计时器**：只有「打开计时器」跳到经典模式；Focus 页落地后替换。
4. **`ViewTabs` 组件保留但无引用**：为内部回退留的；建议 Focus/History 落地后删除（连同 C22 测试）。
5. **首屏下方仍有空白**（数据少时）：没有用固定高度或占位卡片填满，避免"为了好看加内容"。
6. **深色只在模拟 token 下测**：宿主真实皮肤叠加未验证。
7. **数据零迁移**：存储 Schema 未动；老用户数据直接可读（smoke 覆盖 V1–V4 兼容）。
