## 3. 为什么没有宿主截图（四条，全部实际尝试过）

1. **窗口不可见**：`ffmpeg -f gdigrab -i desktop` 抓到的前台是另一个应用；
   `-i title="DeepSeek Harness"` 与 `-i hwnd=0x6078E` 都只得到 **153 B 的 0×0 空帧**
   （窗口最小化或未显示时，窗口 DC 抓不到内容）。
2. **不能加调试参数**：约束禁止用 remote debugging 重启 DSH；现有进程没有调试端口，
   因此无法读取 DOM、计算样式或控制台。
3. **PowerShell 截图被安全策略拦截**：
   `Add-Type`（"compiles and loads .NET code"）与 `Assembly.Load`（"Reflection.Assembly load APIs"）
   均被拒绝，无法用 `PrintWindow` / `CopyFromScreen` 绕开前台限制。
4. **不能重启/重新加载**：约束禁止启动、重启 DSH；我也不会向用户正在使用的窗口注入
   快捷键（Ctrl+R）或鼠标点击来切换页面/主题。

> 结论：在没有窗口焦点、没有 CDP、没有截图 API 的前提下，
> **任何"我看到了玻璃效果如何"的描述都会是编造**，因此本节不做视觉判断。

## 6. 宿主打开后的验收清单（建议逐项打勾）

### 6.1 环境与材质

- [ ] 页面不是纯白/纯灰平涂：**能看出**左上玫瑰、右上淡紫的色相变化；
- [ ] L1 面板（统计带、今日任务、近 7 日、Tasks 列表）内部有**通透感**：
      背景色透过面板仍可辨认，但文字没有被染色；
- [ ] L1 顶部有一条**细高光**，底部有轻微内侧阴影（厚度感），不是硬白描边；
- [ ] L2（最近活动、项目概览）明显比 L1 **更轻**：更透、投影更浅、没有斜向反光；
- [ ] 面板底部有**接触阴影**，与背景分离但不"发黑一圈"；
- [ ] 没有出现：过度发白、发灰、浑浊、彩色边缘、霓虹描边。

### 6.2 深色

- [ ] 背景是深紫灰（`#17151b`），不是纯黑；
- [ ] 深色面板顶部高光**克制**（不是白边），底部内侧阴影可见；
- [ ] 11px 辅助文字（卡片右上说明、任务元信息）在深色下**能读**；
- [ ] 深浅切换后没有残留的浅色光斑/白边。

### 6.3 布局与交互

- [ ] 页面与 DSH 主容器：圆角、左右边距、滚动条不打架；**没有出现第二层滚动**；
- [ ] 统计带在窄窗口变成 2×2，分隔线连续、不发虚；
- [ ] 卡片 hover 只变边框/阴影，**不位移**（位移会引发已知的闪烁 bug）；
- [ ] Tasks：行 hover 有淡淡的底色，编辑/删除按钮不再是大描边药丸；
- [ ] 输入框 focus 有玫瑰色边框 + 柔光圈，键盘 Tab 可见；
- [ ] 页面切换有约 200ms 淡入，不闪白。

### 6.4 控制台

- [ ] DevTools Console 无红色错误（尤其 `backdrop-filter` / `color-mix` / CSS 解析错误）。
