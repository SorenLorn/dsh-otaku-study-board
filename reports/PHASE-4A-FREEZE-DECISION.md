## 2. 关于 `!important` 与选择器优先级的修订

原报告的说法需要收紧：

- 普通内联 `style`（author normal）**高于**普通作者规则，所以普通 CSS 覆盖不了它；
- 作者 `!important` **能**压过普通内联；
- 但若内联本身是 `!important`，它属于「作者重要声明」，且内联优先级最高，普通作者 `!important` 压不过；
- 选择器优先级要逐条算，不能凭「类选择器一定赢」：例如
  - `.v4-tab[aria-selected="true"]` → `(0, 2, 0)`
  - `body[data-ds-dark-theme] button` → `(0, 1, 2)`
  - 前者类数量 2 > 1，通常胜出；但宿主若写成 `body[data-ds-dark-theme] .app button`（`(0, 2, 2)`）就会反超。
- 如果根因是 token 没继承，加背景 `!important` 只会掩盖问题。

**因此：在拿到 computed style 之前，不实施任何 Tab 覆盖。**
